Desloque Party

Aplicación web progresiva para crear espacios privados por invitación en eventos como bodas, fiestas y aniversarios.

Problema que resuelve

Concentrar recuerdos y participación de invitados en un espacio privado, accesible desde móvil, sin depender de grupos dispersos o plataformas públicas.

Solución desarrollada

PWA con espacios privados por membresía, galería multimedia, reacciones, comentarios y notificaciones push para mantener la interacción activa.

Funcionalidades principales

  • Subida de fotos y videos con conversión HEIC a JPEG.
  • Reacciones y comentarios dentro de cada espacio.
  • Notificaciones Web Push para miembros.
  • Almacenamiento privado con políticas RLS en Supabase.

Tecnologías utilizadas

React 19ViteTailwind 4SupabasePWAVercel

Mi participación
